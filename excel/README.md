# Excel Analysis & Data Preparation

This directory contains Microsoft Excel workbooks (`.xlsx`) used for initial data profiling, validation, and exploratory pivot table analysis.

### Planned Contents:
- **Data Quality Check Sheet**: Spot checks for missing values, blank rows, and data type validation.
- **Pivot Table Analysis**: Initial summaries of sales by category, monthly trend summaries, and discount impact calculations.
- **Formula Reference**: Key formulas used (`XLOOKUP`, `SUMIFS`, `IFERROR`, `TEXT`, `DATEDIF`).
