# SQL Analysis & Queries

This directory will host all structured SQL scripts for data management and analytical querying.

### Script Breakdown:
1. `01_schema_setup.sql`: Table definitions, primary/foreign keys, and staging table creation.
2. `02_data_cleaning.sql`: Data type casting, trimming whitespace, deduplication, handling null values.
3. `03_eda.sql`: Aggregations, order volume distributions, categorical summaries.
4. `04_business_kpis.sql`: CTEs, Window functions (`ROW_NUMBER`, `DENSE_RANK`, `LAG`, `LEAD`), Month-over-Month (MoM) growth, and customer lifetime order frequency.
